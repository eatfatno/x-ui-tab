首个 GitHub Docker 发行版（本地 1.0.0 的修订版），基于官方 3x-ui **v3.9.0**，增加独立流量监测 Tab，并提供 Linux `x-ui` 管理菜单。

- 按客户端查询上传、下载、合计、实时速度及访问目标，支持精确到分钟的时间范围。
- 1,411 个服务组、24,541 条域名规则，合并展示同一服务的网页与 App 访问。
- 访问明细最多 7 天，客户端流量与访问次数汇总最多 35 天。
- 支持按客户端与时间范围删除监测记录及采样用量。
- 独立数据库和界面适配层，提供备份恢复、镜像更新失败恢复及配置持久化。
- 修复首次启动期间健康检查可能提前创建空数据库、导致随机凭证文件缺失的问题。
- Docker 包已验证登录、官方常用页面、监测页面、REALITY 本地代理、备份恢复及重建。

支持 **Linux amd64 / x86_64**。一键安装自动准备依赖支持 Ubuntu 22.04/24.04；其他发行版需预装 Docker Engine、Compose v2、Python 3.10+、curl、util-linux。

```bash
curl -fsSL https://raw.githubusercontent.com/eatfatno/x-ui-tab/v1.0.1/scripts/install-online.sh | sudo bash -s -- --version v1.0.1
```

默认入口 `http://服务器IP:18080/panel/?monitor=traffic`。安装目录 `/opt/x-ui-tab`；随机账号密码文件 `/opt/x-ui-tab/data/state/credentials.json`。`sudo x-ui` 打开管理菜单，已有其他 x-ui 安装时使用 `sudo x-ui-tab`。

两个附件须保持原名：`.tar.gz` 是含 Docker 镜像的部署包，`.sha256` 是校验文件。部署包不含开发机账号、数据库、代理链接或访问历史。

访问日志提供目标域名/IP，不提供每个目标的精确字节数或 HTTPS 路径；流量以客户端累计值采样为依据。TLS 使用已有证书导入，不内置 ACME 自动申请。ARM 及 GitHub 在线升级菜单未包含。

完整说明见 [Docker 部署文档](https://github.com/eatfatno/x-ui-tab/blob/v1.0.1/docs/docker-deployment.md)，上游许可和构建期间源码归档被 Defender 隔离的记录均保留在文档中；未据此作出误报或无恶意软件结论。
