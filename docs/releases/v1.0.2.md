x-ui-tab v1.0.2 基于 [MHSanaei/3x-ui v3.10.2](https://github.com/MHSanaei/3x-ui/releases/tag/v3.10.2)，内置 Xray 26.10.10。保留独立流量监测、域名服务分类、分钟筛选、7 天访问明细和 35 天用量汇总，由 eatfatno 维护，属于非官方扩展。

本次加入 3.10.2 页面与接口兼容，覆盖 REALITY 二维码和官方页面动态模块；从 v1.0.1 的真实访问历史测试数据库升级，并在官方迁移后注入失败验证旧镜像与数据恢复。一键安装改用 GitHub 官方 API 分段下载、有限重试与完整 SHA-256 校验。

全新 Ubuntu 22.04/24.04 amd64 服务器安装：

```bash
curl -fsSL https://raw.githubusercontent.com/eatfatno/x-ui-tab/v1.0.2/scripts/install-online.sh | sudo bash -s -- --version v1.0.2
```

若 raw 域名访问失败，可用相同版本的官方 API 入口：

```bash
curl -fsSL -H 'Accept: application/vnd.github.raw+json' 'https://api.github.com/repos/eatfatno/x-ui-tab/contents/scripts/install-online.sh?ref=v1.0.2' | sudo bash -s -- --version v1.0.2
```

其他 Linux 先准备 Docker Engine、Compose v2、Python 3.10+ 等依赖，再加 `--no-install-deps`；CentOS Stream 等开启 SELinux 的系统按部署文档配置数据目录标签。无需 Windows 或 WSL。

默认入口 `http://服务器IP:18080/panel/?monitor=traffic`。首次随机凭证在 `/opt/x-ui-tab/data/state/credentials.json`，管理命令 `sudo x-ui`；已有其他 x-ui 时使用 `sudo x-ui-tab`。

已有本项目 v1.0.1 的用户按 [升级说明](https://github.com/eatfatno/x-ui-tab/blob/v1.0.2/docs/upgrade-v1.0.2.md) 载入新镜像，再从**原部署目录**执行 `x-ui update x-ui-tab:3.10.2-1.0.2-amd64`。无需重新初始化，升级前自动备份，失败自动恢复；数据库不支持直接降级。

附件为 Linux amd64 Docker 离线包和整体校验文件；包内另有 `SHA256SUMS`、源码、许可证和验收报告。只部署服务器所需成品，不包含开发缓存、个人凭证或访问历史。旧 v1.0.1 发布包保持原样。

验收范围与资源口径见 [升级说明](https://github.com/eatfatno/x-ui-tab/blob/v1.0.2/docs/upgrade-v1.0.2.md) 和 [资源说明](https://github.com/eatfatno/x-ui-tab/blob/v1.0.2/docs/resource-assessment.md)。实际验证使用 WSL Ubuntu 24.04 的独立 Docker 环境，未实机验收 CentOS、ARM、新装操作系统的依赖安装，以及新增 MASQUE/XDRIVE/TUN。Windows Defender 对旧官方完整源码压缩包的隔离记录保留，该压缩包不参与本次构建或交付。
